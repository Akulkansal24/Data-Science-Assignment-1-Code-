## How to Reproduce All Results

Both scripts automatically handle downloading and preprocessing the KDD Cup 1999 dataset (`n = 494,021`, `d = 116` after one-hot encoding, dropping constant features, and min-max scaling to `[0, 1]`).

### 1. Run Question 1 Experiments ($k$-Means Clustering)

Executes the random projection pipeline for $k$-means clustering:
```bash
python Q1_code.py
```

**What this script does:**
1. **Data Preprocessing**: Processes KDD Cup 1999 to produce matrix $D \in \mathbb{R}^{494021 \times 116}$ and saves a local cache (`kdd_preprocessed.npz`) for rapid subsequent runs.
2. **Part 1(a) — Baseline $k$-Means**: Fits exact Lloyd's $k$-means on ambient data $D$ with $k=15$ clusters and $n\_init=5$, recording baseline cost $\mathrm{cost}(D, B)$ and runtime.
3. **Parts 1(b, c, d) — Random Projections & Centroid Reconstruction**:
   - Tests projected target dimensions $m \in \{5, 10, 15, 20, 25\}$ across 5 repetitions each using fresh Gaussian matrices $A \sim \mathcal{N}(0, 1/m)$.
   - Explicitly records matrix projection time $E = DA^T$ ($28\text{--}51\text{ ms}$) separately from Lloyd clustering time on $E$.
   - Computes both **row-averaged centroids** $\hat{B}$ and **pseudo-inverse mapped centroids** $B^+ = a A^+$.
4. **Part 1(e) — Concentration of Measure**:
   - Samples $10^4$ strictly distinct pairs ($D_i \neq D_l$) to measure pairwise distance preservation $\|E_i - E_l\|^2 / \|D_i - D_l\|^2$.
   - Evaluates aggregate clustering cost preservation $\mathrm{cost}_E(\mathcal{C}_D) / \mathrm{cost}_D(\mathcal{C}_D)$ over 20 independent draws of $A$ and validates empirical variances against the theoretical effective rank $r \approx 17.4$.
5. **Outputs**: Saves figures to `results/figures/` and complete numerical metrics to `results/all_results.json`.

### 2. Run Question 2 Experiments (Linear Regression & CountSketch)

Executes the sketch-and-solve regression pipeline:
```bash
python Q2Code.py
```

**What this script does:**
1. **Part 2(a) — Full Least Squares Baseline**:
   - Computes exact minimum-norm least-squares weights $b = \arg\min_a \|Da - y\|_2^2$ on full $D$ and attack labels $y$.
   - Identifies $\mathrm{rank}(D) = 113$ (due to linear dependencies in one-hot encodings) and baseline loss.
2. **Parts 2(b, c) — CountSketch Sketch-and-Solve**:
   - Projects $[D \mid y]$ using an implicit $O(nd)$ CountSketch $S$ without materializing the projection matrix.
   - Evaluates sketch dimensions $m \in \{50, 100, 200, 500, 1000, 2000, 5000\}$ across 5 runs each.
   - Solves $\tilde{a} = \arg\min_a \|SDa - Sy\|_2^2$, measures true loss $\mathrm{Loss}(D, y, \tilde{a})$, sketched loss, and wall-clock speedup vs. baseline solve.
3. **Part 2(d) — Residual Norm Preservation**:
   - Tests residual vector $v = Db - y$ across 100 independent CountSketches for $m \in \{50, 500, 5000\}$.
   - Evaluates empirical mean, variance, and histograms of $\|Sv\|^2 / \|v\|^2$ against theoretical $\sqrt{2/m}$ limits.
4. **Part 2(e) — CountSketch vs. Dense Gaussian Projection**:
   - Benchmarks CountSketch against dense Gaussian sketching $\mathcal{N}(0, 1/m)$ on a 50,000-row subset at $m = 500$ across 5 repetitions.
   - Compares sketch application time (showing a ~26× speed advantage for CountSketch) and regression accuracy.
5. **Outputs**: Generates summary tables and CSV logs in `out_q2/`, console log `out_q2/results_q2.txt`, and plots (`fig_b_ratio_and_sketched_loss.png`, `fig_c_time.png`, `fig_d_hist.png`).
